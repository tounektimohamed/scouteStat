## 📖 Overview

**ScouteStat** is a statistics companion for scout leaders, letting units track and visualize their activities on mobile.

## ✨ Features

- Unit activity tracking
- Statistics & visualization
- Cross-platform mobile


## 🛠 Tech Stack

Flutter, Dart.

## 🚀 Getting Started

```bash
git clone <repo-url>
cd <repo>
flutter pub get
flutter run
```
